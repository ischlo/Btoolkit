The goal of Btoolkit is to simplify certain workflow. It’s a package
that contains support function for use with `sf`, `cppRouting`,
`cppRnet` among others. Some functions have general applications.

## Installation

You can install the development version of Btoolkit from
[GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("ischlo/Btoolkit")
pak::pak("ischlo/Btoolkit")
```
